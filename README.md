## Overview

Restaurant Review RAG is a Retrieval-Augmented Generation (RAG) application that answers user queries about restaurant reviews using semantic search and a locally hosted Large Language Model (LLM).

The application retrieves the most relevant reviews from a vector database and provides context-aware responses generated by the language model, improving the accuracy and relevance of the answers.

---

## Features

- Retrieval-Augmented Generation (RAG)
- Semantic search over restaurant reviews
- Local inference using Ollama
- Vector embeddings using mxbai-embed-large
- ChromaDB vector database for efficient retrieval
- LangChain for prompt orchestration
- Interactive command-line interface

## Installation

### Clone the Repository

```bash
git clone https://github.com/ramitharavichandra/restaurant-review-rag.git
cd restaurant-review-rag
```

### Create a Virtual Environment

```bash
python3 -m venv venv
```

### Activate the Virtual Environment

macOS/Linux

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Install Required Ollama Models

Install Ollama from:

https://ollama.com/download

Download the required models:

```bash
ollama pull llama3.2
```

```bash
ollama pull mxbai-embed-large
```

Start the Ollama service before running the application.

## Workflow

1. Load restaurant reviews from the CSV dataset.
2. Generate embeddings using the embedding model.
3. Store embeddings in ChromaDB.
4. Retrieve the most relevant reviews for the user's query.
5. Pass the retrieved context to the language model.
6. Generate and display the final response.
